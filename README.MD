🌍 Global Tech Founders Catalog

A web-based catalog showcasing influential technology founders from around the world. Users can browse through founder profiles, search by name, and navigate between entries interactively.

📖 Project Overview

This project is a data catalog web application built with HTML, CSS, and JavaScript. It provides a card-based layout to display founder profiles, including:

Name

Company

Industry

Country

Background

Key Contribution

Net Worth

Profile Picture

Website Link

Users can:

🔍 Search for founders by name.

⬅️➡️ Navigate between profiles using Previous/Next buttons.

🗑️ Remove a founder entry dynamically.

📱 View clean, responsive card layouts.

🛠️ Tech Stack

HTML5 → Structure of the app.

CSS3 → Styling, layout, responsiveness, and hover animations.

JavaScript (Vanilla) → Handles interactivity, DOM manipulation, filtering, and navigation.

📂 Project Structure
.
├── index.html      # Main HTML file
├── style.css       # CSS for styling and layout
├── scripts.js      # JavaScript for logic and interactivity
└── assets/         # (Optional) Local images for founders

🚀 Features

✅ Card-based UI – Each founder appears on an interactive card.
✅ Dynamic Navigation – Move between profiles using Next/Previous buttons.
✅ Search Functionality – Find specific founders instantly.
✅ Remove Functionality – Remove a founder card from the catalog.
✅ Hover Animation – Cards scale slightly when hovered for better UX.
✅ Responsive Design – Works across different screen sizes.

⚡ Usage

Clone or download this repository:

git clone https://github.com/your-username/global-tech-founders.git
cd global-tech-founders


Open index.html in your browser:

open index.html


Interact with the catalog:

Use the search bar to find a founder by name.

Click Next or Previous to cycle through profiles.

Click Remove to delete the currently displayed founder.

Click the Visit Website button on each card to view external profiles.
